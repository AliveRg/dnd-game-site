# Деплой на Timeweb Cloud App Platform

Схема: **GitHub → App Platform (Dockerfile) → контейнер Node на порту 3000 → Timeweb сам вешает nginx + SSL на 80/443**.
Открывать порты и ставить сертификат руками не нужно — это делает платформа. SSH/root-пароль для App Platform **не нужен** (это не VPS), не пересылай его в чатах.

## 1. Репозиторий

```bash
cd "~/vs code/dnd game site"
git init -b main
git add .
git commit -m "init: nuxt + docker"
git remote add origin git@github.com:<you>/<repo>.git
git push -u origin main
```

`.env` в git не попадает (`.gitignore`). Все секреты — только в переменных App Platform.

## 2. Создание приложения

App Platform → **Создать** → тип **Docker** → подключить GitHub → репозиторий.

| Поле | Значение |
|---|---|
| Ветка | `main` |
| Коммит | Сборка по последнему коммиту |
| Автодеплой | **Включить** (каждый push в main = обновление сайта) |
| Фреймворк | **Dockerfile** (не Vue! панель увидит package.json и предложит Vue — игнорируем) |
| Путь до директории проекта | `/` (корень). **Не** `/Dockerfile` — это была ошибка в старом проекте |
| Путь проверки состояния | `/api/health` |
| Регион | тот же, что у БД (для приватной сети) |

Порт платформа берёт из `EXPOSE 3000` в Dockerfile.

## 5. Домен и SSL

Домена пока нет — сайт работает на техническом адресе Timeweb и закрыт от индексации (`NUXT_PUBLIC_INDEXABLE=false`). Когда купят домен:

1. App Platform → приложение → **Домены** → добавить `домен.ru` и `www.домен.ru`.
2. У регистратора: A-запись (или CNAME) на адрес, который покажет панель.
3. SSL Let's Encrypt платформа выпустит сама после того, как DNS обновится (обычно до нескольких часов).
4. Включить редирект www → без www (или наоборот) — один вариант должен быть главным для SEO.
5. Поменять `NUXT_PUBLIC_SITE_URL` на домен и `NUXT_PUBLIC_INDEXABLE=true` → передеплой.

## 6. Яндекс Метрика + Вебмастер

1. metrika.yandex.ru → новый счётчик → домен. Включить Вебвизор. Номер — в `NUXT_PUBLIC_YANDEX_METRIKA_ID`.
2. Цели (тип «JavaScript-событие»): `booking_sent` (заявка из календаря), `hero_form_sent` (форма на первом экране).
3. webmaster.yandex.ru → добавить сайт → подтвердить → «Файлы Sitemap» → `https://домен.ru/sitemap.xml`. Регион сайта → город клуба.
4. Яндекс Бизнес: карточка организации с адресом — сильно помогает локальному SEO и картам.

## 7. Почта

Яндекс 360: Настройки → Безопасность → **Пароли приложений** → «Почта» → этот пароль в `NUXT_SMTP_PASS`.
Проверка: отправить тестовую заявку с сайта → письмо на `NUXT_MAIL_TO` + запись в `/dragons`.
