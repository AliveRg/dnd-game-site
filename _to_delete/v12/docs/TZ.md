# ТЗ: сайт клуба настольных ролевых игр «Хижина Всякой Всячины»

## 1. Цель
Собирать заявки на партии (D&D 5e и другие НРИ) через сайт: показать атмосферу, сюжеты, цены и дать записаться на конкретную дату. Трафик — SEO (Яндекс) + Яндекс Директ. Город — **Белгород**.

## 2. Аудитория
- Новички, которые хотят попробовать D&D «вживую» (главный сегмент для акции 2000 ₽).
- Опытные игроки, ищущие мастера и необычные сюжеты (хоррор, детектив, высокоуровневый D&D).
- Компании друзей / пары (истории на двоих, день рождения).

## 3. Стек и инфраструктура
| | |
|---|---|
| Фронт/бэк | Nuxt 4 (Vue 3, SSR), Tailwind CSS 4, Node.js LTS |
| БД | PostgreSQL 18 (Timeweb DBaaS) |
| Файлы | S3 Timeweb (`s3.twcstorage.ru`, бакет `703eb6ea-…`), отдача через `/media/*` |
| Почта | SMTP (nodemailer), адрес получателя — переменная `NUXT_MAIL_TO` |
| Хостинг | Timeweb App Platform, Dockerfile, автодеплой по push в `main`, SSL от платформы |
| Аналитика | Яндекс Метрика (Вебвизор, цели на заявки, UTM в заявке) |

## 4. Страницы
| URL | Содержание |
|---|---|
| `/` | Главная (блоки ниже) |
| `/games` | Все сюжеты + фильтр Ваншот / Модуль / Кампания |
| `/games/:slug` | Страница сюжета: описание, система, игроки, уровень, жанры, 18+, кнопка записи |
| `/news`, `/news/:slug` | Новости / Новинки / Статьи (вкладки) |
| `/privacy` | Политика ПД (152-ФЗ) |
| `/dragons` | Админка (закрыта от индексации) |

## 5. Главная — блоки по порядку
1. **Первый экран:** фон — анимация из фото (смена кадров + медленный зум); заголовок «Клуб настольных ролевых игр D&D [город]»; плашка **«Акция: партия 4 часа — 2000 ₽»**; короткая форма (имя + Telegram/VK/e-mail + согласие). **Телефон не собираем** (звонить некому).
2. **О клубе:** короткий текст + 4 преимущества (новая история каждую неделю, атмосфера, можно новичкам, до 5 игроков).
3. **Уникальные сюжеты и миры:** 6 карточек + «Все сюжеты».
4. **История недели:** каждую неделю — новая история в новом сеттинге (партия с флажком «История недели» в админке). *Сейчас выводится бейджем в календаре; отдельный блок — в дизайне.*
5. **Цены — 3 тарифа:**
   - 4 часа — **2000 ₽** (акция до 31.01.2027, далее 2500 ₽);
   - 6 часов — **3000 ₽**;
   - по приглашению, 4 часа — **1500 ₽**;
   - пригласившему **−500 ₽ за каждого друга** на 4-часовую партию, но не больше 25%.
6. **Запись — календарь:** дни с партиями подсвечены, у партии видно свободные места (**максимум 5 на партию**), форма с тарифом, кол-вом мест, «кто пригласил», комментарием и расчётом примерной стоимости. Можно отправить заявку без даты.
7. **FAQ** (с разметкой FAQPage для Яндекса).

## 6. Логика заявки
- Проверка свободных мест в транзакции (два человека не займут последнее место).
- Сохранение в БД → письмо на `NUXT_MAIL_TO` → цель в Метрике.
- Антиспам: скрытое поле-ловушка + лимит 5 заявок / 10 мин с IP.
- UTM-метки с первого захода сохраняются и уходят в заявку.

## 7. Админка `/dragons`
- Вход по логину/паролю (из переменных окружения), cookie-сессия 7 дней, лимит попыток.
- **Заявки:** список, статусы новая / подтверждена / отменена.
- **Расписание:** создать партию (сюжет, дата/время, часы, мест, цена, «история недели», статус).
- **Контент:** сюжеты, новости, новинки, статьи — заголовок, URL, анонс, текст, обложка (загрузка в S3), SEO title/description, параметры сюжета (JSON: система, игроки, уровень, жанры, 18+, цвет).

## 8. SEO
- Title/description/canonical/OG на каждой странице; `sitemap.xml` и `robots.txt` динамические.
- Микроразметка: EntertainmentBusiness (добавить адрес!), FAQPage.
- Ядро 10 000+ запросов под Белгород: `seo/semantic-core.xlsx` (4 группы: широкие / узкие-запись / ключевые / целевые); реальные частоты — скриптом `npm run wordstat`.
- Структура Директа и минус-слова — там же.
- Под каждый сюжет — своя посадочная страница (длинный хвост: «ваншот днд хоррор», «нри на двоих» и т.п.).

## 9. Нефункциональные требования
- LCP < 2,5 с на мобильном 4G; картинки webp/avif, hero ≤ 250 КБ.
- Адаптив от 360 px.
- Согласие на обработку ПД в каждой форме; политика ПД.

## 10. Решения и допущения (13.11.2026)

| Вопрос | Решение | Статус |
|---|---|---|
| Город | **Белгород** | подтверждено |
| Домен | пока нет, купят позже. Сайт живёт на техническом адресе Timeweb, закрыт от индексации (`NUXT_PUBLIC_INDEXABLE=false`) | ждём домен |
| Название | «Хижина Всякой Всячины» | по текстам заказчика |
| Цены | только тарифы: **1500 / 2000 / 3000 ₽**. Цены 400–500 ₽ из описаний сюжетов убраны | подтверждено |
| Скидка за друзей | −500 ₽ за друга, **не больше 25%** от цены пригласившего (на 4-часовой партии это максимум 500 ₽) | подтверждено |
| Срок акции 2000 ₽ | до **31.01.2027** (~2,5 месяца — типичный срок стартовой акции) | допущение по рынку |
| Цена 4 часа после акции | **2500 ₽** | допущение по рынку |
| Отмена записи | бесплатно не позже чем за 24 ч | допущение по рынку |
| Возраст | с 14 лет (до 16 — с согласия родителей), сюжеты 18+ помечены | допущение по рынку |
| Время игр | будни с 18:00, выходные днём и вечером | допущение по рынку |
| Текст «О клубе» | черновик на сайте, заменить текстом заказчика | ждём текст |

**Цены по рынку (для ориентира, ваншот с человека):** Омск — 600 ₽ за 3–4 ч; Казань — от 1200 ₽; Красноярск — 1800 ₽ за 3–5 ч; клубы СПб и других крупных городов — 1800–2200 ₽, отдельная игра с мастером в выходные — до 3000 ₽.
Вывод: 2000 ₽ за 4 часа — уровень клубов-миллионников; для Белгорода это верх рынка. Поэтому акцию стоит держать, а 2500 ₽ после неё — проверить на конверсии заявок.

## 11. Что ещё нужно от заказчика
1. Адрес клуба (для карточки в Яндекс Бизнесе, Директа и разметки).
2. Telegram / VK клуба, e-mail для заявок, ящик для SMTP.
3. Фото: обложки сюжетов, помещение, мастер.
4. Текст «О клубе» и о мастере.
5. Реквизиты для политики ПД (ИП/самозанятый, ИНН); уведомление в Роскомнадзор как оператора ПД.
6. Yandex Cloud: **folderId** каталога с ключом Wordstat (для `npm run wordstat`).
7. Подтвердить допущения из таблицы выше.
