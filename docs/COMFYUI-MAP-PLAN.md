# План: карта миров из локаций, сгенерированных в ComfyUI

Статус: **первая версия на сайте (13.11)** — карта собрана из двух генераций (tools: склейка в Python), зоны в shared/map-zones.ts, компонент MapExplorer. Дальше — заменить на low-poly плитки из ComfyUI.

> ⚠ Напомнить, когда переходим к правкам страницы «Сюжеты и карта» (/games).

## Идея
Вместо одной плоской карты — **архипелаг миниатюр**: каждый регион отдельная low-poly 3D-плитка (изометрия, как на референсе с Хребтом Гроссглокнер), сгенерированная локально в ComfyUI на прозрачном фоне. На сайте плитки раскладываются по «столу» (тёмное дерево + туман), у каждой своя зона клика и сюжеты.

## Как генерировать (единый стиль серии)
1. Один **базовый промт-шаблон** + блок региона:
   `miniature low-poly 3D tabletop terrain tile, isometric 30°, square base with thick dark earth sides, soft studio light from top-left, warm muted palette, no text, isolated, transparent background — {РЕГИОН}`.
2. **Фиксированные**: сид-диапазон, размер 1024×1024, одинаковый угол и толщина основания. Для одинаковой перспективы — img2img или ControlNet-depth от одной «пустой» плитки-основы (сгенерировать один раз и подавать как каркас).
3. Удаление фона: BiRefNet / RMBG-2.0 нода в ComfyUI → PNG с альфой → конвертация в webp (≤ 250 КБ на плитку).
4. Отбраковка: 4–8 вариантов на регион, выбираем лучший, при необходимости inpaint деталей (замки, маяки).

## Как собрать на сайте
- **Вариант A (рекомендую): DOM/SVG-сцена.** Плитки — `<img>` с абсолютными координатами на «столе» 2400×1600, обёртка с pan/zoom (CSS transform). Зона клика — полигон по контуру плитки (генерим из альфа-канала автоматически скриптом → `clip-path`/SVG `<polygon>`). Ховер: плитка приподнимается (translateY −8px), золотое свечение по контуру, поверх — подпись региона.
- **Вариант B: Leaflet (как сейчас).** Каждая плитка — `L.imageOverlay` в своих границах, клик по полигону. Плюс: готовые зум и мобильные жесты. Минус: «миниатюрность» и подъём плитки сложнее.
- Клик по региону → боковая панель (или TarotCard-колода) со списком сюжетов региона + «Записаться».
- Туман войны: облака (webp с альфой) поверх неоткрытых регионов, рассеиваются при наведении/по мере записи.
- Мобилка: регионы списком-каруселью плиток, сцена с pan/zoom только на планшете+.

## Данные
- В админке у региона: картинка плитки, координаты на столе, полигон клика (авто), список сюжетов.
- Таблица `regions` (id, slug, title, image, x, y, w, polygon jsonb) + `posts.meta.region`.
