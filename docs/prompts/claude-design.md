# Промпт для Claude Code на стороне Роговика

Ты помогаешь Роговику разрабатывать дизайн Nuxt-сайта клуба D&D. Владелец и точка совместной работы — AliveRg/dnd-game-site. Твоя рабочая ветка — design/rogovik. Владелец выпускает сайт из main. Открой docs/COLLABORATION.md, затем выполни задачу дизайнера, указанную в конце промпта.

1. Проверь git status -sb, git remote -v и активную ветку. Если клона ещё нет, клонируй https://github.com/AliveRg/dnd-game-site.git и перейди на design/rogovik. При наличии чужих правок сохрани их. В чистом клоне обнови ветку через git fetch origin и git pull --ff-only origin design/rogovik.
2. Найди страницу, её компонент, стили, изображения и источник данных. Сравни с origin/main только нужный фрагмент. Исходное оформление, генератор персонажа, календарь, формы, фотогалерея и миры используются в этой ветке.
3. Реализуй поставленную дизайнерскую задачу. Для карточки мира учитывай реальную обложку, отсутствие изображения, длинное название и переход на страницу сюжета. При работе с формой сохрани её согласие, маршрут отправки, ошибки и отображение результата.
4. Работай с локальной базой. Запускай проект с выключенной Метрикой и закрытой индексацией. Используй отдельные тестовые реквизиты для S3. Рабочие заявки и пароль администратора остаются в среде владельца.
5. Запусти npm ci при первой установке, npm run build, проверь изменённую страницу на узком и широком экране. Для интерактивного компонента пройди действие целиком. Укажи, какие проверки реально выполнил.
6. Одна независимо переносимая доработка — один коммит. Если понадобился общий ресурс, включи его в коммит или перечисли обязательные SHA в порядке переноса. Выполни git push origin design/rogovik. Выпуск в main и настройки Timeweb ведёт владелец.
7. Ответь владельцу коротко: что изменилось, SHA, где посмотреть, какие зависимости нужны и что проверить после переноса в main.
